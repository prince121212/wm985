# 文明知识库：免费资源激励广告接入

## 用户流程

资源详情仍可正常浏览。用户点击“看广告免费获取”后，创建绑定当前用户和资源的广告会话，播放现有激励视频，收到 `res.isEnded === true` 才调用访问接口获取链接并复制。提前关闭、没有完成标记、广告报错、配置/登录/接口失败都不复制；不再用详情中的 `file_url` 兜底。

积分资源维持“确认扣积分 → 访问接口 → 复制”流程。若用户同意的是免费广告解锁，而资源随后变为积分资源，接口拒绝此次免费请求，页面刷新后重新征求扣分确认。

按钮有处理中锁；离开页面取消本次操作，旧SDK回调不会触发复制。复制失败时可在当前页面重试已获取的链接，不再次看广告或扣积分。复制成功后不保留永久免广告权限，下次主动获取仍需观看。广告已完成但接口网络失败，可在会话有效期内重试原凭证，不重复观看；服务器明确拒绝后则重新获取凭证。

## 广告位与接口

- 小程序：文明知识库，AppID `wx6800a178fb2307f8`。
- 已在后台核对的激励广告位：`adunit-6d5a31d80528afc5`，名称“看完广告即可免费下载”。
- 默认使用这个公开广告位ID，无需往客户端放置 AppSecret 或数据库密钥。
- `GET /api/mp/ads/config`：返回开关、广告位ID、策略版本，无用户隐私。
- `POST /api/mp/resources/[id]/ad-session`：需小程序登录；仅对已审核、零积分资源创建10分钟会话。
- `POST /api/mp/resources/[id]/access`：新版免费资源必须提供 `{ad_session_id,ad_completed:true}`；校验用户、资源、广告位、有效期后返回链接。重复请求同一会话在有效期内可取回结果，不重复统计访问。
- 新版统一请求头为 `X-MP-Resource-Access-Version: 1`。携带此头的小程序列表、详情、收藏响应不提前发送 `file_url`；资源作者自己的上传信息和网站原有资源流程保持原有行为。

可选服务器环境变量（均非密钥）：

```text
MP_REWARDED_AD_UNIT_ID=adunit-6d5a31d80528afc5
MP_REWARDED_AD_ENABLED=true
MP_ALLOW_LEGACY_RESOURCE_ACCESS=true
```

未配置时使用上述已核对的广告位。`MP_REWARDED_AD_ENABLED=false` 表示新版广告获取暂不可用，**不会自动放行新版免费资源**。配置加载失败同样不复制链接。

## 新旧版本兼容

当前线上旧版尚无广告播放能力，而且复制函数会先检查详情中的 `file_url`，缺失就中止，连积分资源也无法领取。等待微信审核期间，后端对没有版本头、也未声明广告会话的旧请求保留原有响应和领取行为，防止先部署后端导致线上旧版不可用。

新版每次请求都声明版本头，失败时不删除该头重试、不降级到旧协议。请求体只要包含 `ad_session_id` 或 `ad_completed` 字段，即使漏传版本头，也必须校验广告凭证；畸形 JSON 不会作为旧版免费请求放行。任何已出现的版本头（包括空值、未知值）也不会触发旧版兼容。

`MP_ALLOW_LEGACY_RESOURCE_ACCESS` 默认开启兼容；新版审核通过、正式发布并验证稳定后，可在服务器将其设为 `false`，关闭旧协议。关闭后所有浏览请求均剥离链接，所有免费领取都需要广告凭证；仍停留在旧版的用户需更新小程序。这次部署保持兼容开启。

版本头用于渐进发布，**不是防伪凭据**。兼容期间，刻意省略版本头和广告字段的人仍能使用原有免费入口，不能声称所有线上客户端已经强制观看广告。

## 数据库与发布

1. 在当前网站使用的 Supabase 数据库执行 `data/migrations/20261005_mp_resource_ad_sessions.sql`。它只新增会话表、索引和权限，不修改资源、用户或积分表中的数据。新安装也已同步到 `data/install.sql`。
2. 网站服务器使用现有 Supabase 服务端凭据，需配置 `SUPABASE_SERVICE_ROLE_KEY`；新表不允许 `anon` 或 `authenticated` 直接读写。
3. 保持旧协议兼容开启，部署包含新 `/api/mp/*` 逻辑的后端，并在微信开发者工具上传含上述版本头的新版小程序；真机验证实际广告完成回调和剪贴板后提交审核。提交审核不等于正式发布。
4. 后端验收同时核对两种客户端：新版列表不含链接、缺广告凭证领取被拒绝；旧版免费及积分资源仍按原协议可领取。正式发布后再决定关闭旧协议的时间。
5. 不需要新建广告位，不改动后台现有智能广告开关；第一次把这段业务接到小程序仍需要发布新版。

## 校验边界

本实现保证正常客户端只在完整观看回调后请求链接，并通过服务器会话限制跨用户/跨资源使用及重复访问统计。客户端 `isEnded` 并不是微信平台签名的服务端观看证明，当前没有接入广告平台服务端验签；修改客户端的人仍可能伪造自己的完成声明。不能把会话校验宣传为已具备完整广告反作弊。

网站原有免费资源入口仍按网站原规则开放，资源正文、第三方站点本身也可能含链接。本次目标是修正小程序内的获取流程，不是把公开资源改造成全站付费保密内容。

过期会话可在服务器定期清理，例如保留7天后删除；清理应仅针对 `mp_resource_ad_sessions`，不要清空任何生产资源或用户表。
